# Структура проекта

```text
.
├── src/pharmacy/
│   ├── cli.py                 # команды командной строки
│   ├── interactive.py        # интерактивное меню
│   ├── entities/             # бизнес-сущности
│   ├── contracts/             # интерфейсы хранения и DTO
│   ├── services/              # операции аптеки
│   └── database/
│       ├── models/            # SQLAlchemy-модели таблиц
│       ├── repositories/      # запросы к таблицам
│       ├── providers.py       # выбор backend/стратегии
│       ├── sqlite.py          # SQLite-провайдер
│       ├── postgres.py        # PostgreSQL-провайдер
│       └── seed.py            # демонстрационные данные
├── tests/                     # автоматические тесты
├── docs/                      # документация и диаграммы
├── Dockerfile                 # сборка контейнерного образа
├── docker-compose.yml         # запуск контейнера и тома данных
├── pyproject.toml             # метаданные и настройки Python-пакета
└── requirements*.txt          # зависимости
```

`PharmacyService` служит общей точкой входа для бизнес-операций. Он использует узкие сервисы для склада, поступлений, продаж и каталога. Сервисы обращаются к контрактам хранилища, а SQLAlchemy-репозитории реализуют эти контракты. Провайдер управляет подключением и транзакциями.

Бизнес-сущности в `entities` не являются таблицами. Структура таблиц находится в `database/models`; репозитории переводят записи базы в сущности и DTO, используемые остальной программой.
